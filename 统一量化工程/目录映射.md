# 目录映射与保留项

- 前端 UI → `加密量化MVP/src` 与其构建配置
- 中台后端 → `网格和回测可视化`（FastAPI、进度回测执行器、K线服务、tests）
- 网格策略库 → `对冲网格MVP/3_择时策略开发与回测/**`（Signals/Evaluate/Position/参数遍历）

备注: 不采用 freqtrade 的回测引擎，改为使用中台的自研回测执行器与 `对冲网格MVP` 的策略库以支持双向持仓。

- 统一输出位置:
  - 回测结果: `网格和回测可视化/cache/last_result.json`
  - 数据缓存: `网格和回测可视化/K线data/`

统一分层路径：
- `统一量化工程/apps/加密量化MVP`
- `统一量化工程/services/后端中台`
- `统一量化工程/packages/共享协议`
